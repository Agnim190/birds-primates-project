# Birds–primates playback project

Data and code for a field experiment investigating bird responses to primate playback in Kibale National Park, Uganda.

## Repository structure

- `data/raw/` – original data collected in the field
- `data/processed/` – processed datasets used for analysis
- `notebooks/` – Python notebooks for data preprocessing and the experimental-design figure
- `scripts/` – R scripts for statistical analysis and figures
- `figures/` – figures generated for the project

## Analysis

The current analysis examines:

1. whether primate playback has an attractive or deterrent effect on birds;
2. if the effect differs between primate species;
3. if the effect differs among bird feeding guilds.

The statistical analyses are contained in `scripts/01_statistical_analysis.R`, and the corresponding figures are generated by `scripts/02_figures.R`.
